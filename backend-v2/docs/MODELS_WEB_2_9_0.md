# v2.9.0 模型能力与联网服务

本批只迭代 v2，保留 v2.8 的集中设置、悬浮窗与任务提醒修复。

## 模型配置与上下文

设置 → AI 模型支持添加和编辑。填入地址与 Key 后可获取模型列表，也可手填模型名称；编辑原地址、原协议时可用已保存的 Key 获取列表，Key 永不回显。修改地址或协议后，获取列表需重新填写对应服务的 Key。

每个配置可填写上下文窗口、最大输出 token，以及文本、图片、音频、视频输入能力。上下文窗口范围 1,024–10,000,000，最大输出范围 1–1,000,000，输出必须小于上下文；AI 助手必须保留文本输入。模型列表只提供名称，不推断能力或容量。旧数据库启动时幂等补列，旧配置默认仅文本，容量与输出留空，需要按模型说明补充。

最大输出限制在模型构建时设置，对聊天、子代理和单次生成生效；分别映射到 OpenAI Chat 的输出限制字段、Responses 的 `max_output_tokens`、Anthropic 的 `max_tokens`。填写上下文但未指定输出时，聊天按上下文四分之一、至多 4,096 token 设置输出预算。

对话加载时保留按轮摘要，并根据容量触发摘要。每次真正发送请求前，还会把系统指令、工具定义、新消息、附件和工具结果纳入预算，再尝试合并摘要。摘要持久保存到会话，取消后的晚到结果不写库。摘要失败时仅按完整轮次裁剪；最新一轮与工具调用/返回关系不可拆开，仍超限则明确报错。

预算是保守估算，文字参考 UTF-8 字节，图片按尺寸预留，WAV 按时长预留，其他媒体使用固定保守预留；不是服务商精确计数。用户可依据实际服务能力调整容量，不应把估算当成完整支持所有媒体或无限上下文。

## 图片与其他媒体

- 原生支持图片且配置勾选图片：PNG/JPEG/GIF/WebP 字节直接进入模型请求。
- 纯文字模型：使用“设置 → 联网与视觉”中指定的视觉 MCP，把识别结果作为参考文字送给模型。
- 缺少视觉配置、文件读取失败、权限被撤销或工具未返回文字：明确标注附件尚未读取，不先发图片碰运气，也不伪装已看图。
- 接口拒绝已声明支持的媒体时，明确要求检查协议与能力配置，不静默重跑成“已处理”。
- 切换模型后，历史中不支持的媒体不再发给新模型；新工具结果中的媒体也会在每次请求前检查。

当前 OpenAI Chat 接口可原生传 WAV/MP3 音频；Responses 与 Anthropic 适配器不传原生音频。三种当前协议均不传原生视频。视频能力可以记录，但不会绕过协议限制。视觉 MCP 本批仅处理图片，音视频应提供文字稿或关键帧图片。单个媒体读取上限 20 MiB。

视觉 MCP 参数模板支持 `{{image_data_url}}`、`{{prompt}}`、`{{filename}}`、`{{mime_type}}`，以及仅限受信任本地 stdio 服务的 `{{image_path}}`。所选服务器须启用并允许自动执行只读工具，工具须声明只读；连接身份变化后需要重新保存视觉配置。

## 搜索与网页读取

“设置 → 联网与视觉”可分别选择搜索与读取服务：

| 服务 | 搜索 | 正文读取 | 配置 |
| --- | --- | --- | --- |
| 内置 | Bing RSS | 公网 HTML 正文提取 | 默认启用，无需密钥 |
| Tavily | Search API | Extract API | 共用单独保存的 Tavily Key，可选 basic/advanced |
| MCP | 指定只读工具 | 指定只读工具 | 服务器、工具、参数和结果字段映射 |

AI 使用统一 `web_search` / `web_fetch` 工具；学习研究项目的资料搜集、读取与入库使用相同配置。搜索结果保留标题、真实 URL 和摘要；模型需读取关键页面再引用。搜索最多 10 项，网页正文最多 8,000 字符；不代表可执行 JavaScript、登录网站、绕过付费墙或完整浏览所有网站。

Tavily 使用官方 [Search](https://docs.tavily.com/documentation/api-reference/endpoint/search) 与 [Extract](https://docs.tavily.com/documentation/api-reference/endpoint/extract) 接口；本批通过模拟 HTTP 响应验证请求字段、认证与错误处理，未进行付费 Tavily 线上调用。

MCP 参数映射兼容不同的 query、limit、url、URL 数组和正文结果路径。活动配置保存时验证工具及必填参数；非只读工具不能借此绕过审批。连接、凭据、工具或映射变化会使既有绑定失效。失效的非活动 MCP 不妨碍切回内置服务。Tavily Key 存入系统凭据存储，可更换、移除，不写入普通配置或安装包。

内置读取检查公网地址并逐跳检查重定向；远端 Tavily/MCP 在收到初始公网 URL 后负责其后续网络行为。网页、附件和识别结果均作为不可信参考资料，不能改变用户目标或权限。
