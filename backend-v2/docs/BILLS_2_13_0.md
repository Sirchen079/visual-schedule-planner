# v2.13.0 待办账单与支付确认

本轮把房租、订阅、周期费用的提醒和实际记账接起来。用户已要求本轮完成后停止自主迭代；长期私人秘书目标的剩余范围保留在路线文档中，不自动启动下一批工作。

## 使用

个人账本上方新增“待办账单”，支持一次性、每周、每月、每年。首次到期日确定重复基准；每月31日遇二月按月底计算，三月仍回到31日，闰年2月29日的年费按当年月底计算。预估金额可留空，确认支付必须填写实际金额、日期和账户。

每期到期前指定天数和到期当日本机09:00提醒。暂停后停止后续提醒，待处理和历史数据保留。应用关闭期间不在后台运行；重新打开后，对最早未处理期次补发一条到期提醒，避免逐天重复轰炸。通知可以直接打开对应账单。

确认已支付会在同一数据库事务里建立实际支出、关联本期并生成下一期；失败时整体回滚。同一期同内容重试返回原账目，不额外产生支出。已有记账可填账目编号关联，校验未删除的支出及日期、金额、币种和账户，且一笔账目只关联一个期次。账目之后被修改或移入回收站，账单历史显示当前账目状态，重试不会重建或恢复。

用户明确本期无需支付时，可以填写原因跳过；历史可补记支付，补记不会重复生成下一期。每次先处理最早未确认期次，旧期未处理不会自动当作已付。修改名称、预估金额、账户和提醒只更新待处理及未来期次，已处理历史保留。首次到期日和周期确定后不改写，要换日期或周期请暂停原账单后新建。

这不是银行支付、余额同步或自动扣款；待支付账单不进入收支汇总。不同币种仍使用账本原有整数最小单位，日元不允许小数，不推测汇率。仅改动v2，没有改动旧版或正式用户数据。
