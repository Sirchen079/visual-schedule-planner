# 知时 v2.5.0：长材料阅读与原文引用

日期：2026-09-06。仅迭代 v2，私人秘书整体目标仍在进行中。

## 使用

资料库新增正文关键词检索、分段阅读、片段跳转和版本恢复。可搜索整个资料库、单个文件，或从学习项目限定项目材料。检索结果提供原文位置，点击即可阅读对应片段。完成解析后资料列表立即刷新；尚未解析显示「待解析」。

对话附件和项目资料明确标为开头预览。Agent 获得文件编号、解析范围与下一步工具，可以先检索问题相关内容，再读取命中原文；也可按返回的下一片段顺序继续阅读。原有结构化课表预览保留，不把整份长文塞入一次工具结果。

学习步骤可附带 `source_refs=[{source_id,part,revision,quote}]`。程序验证来源归属、解析版本、片段编号和原文摘录，在预览与实际落实时均检查。伪造摘录、过期版本或已删除资料不能作为新计划引用。出处保存进真实任务，重排后仍保留；任务和方案界面可直接打开所引用片段。

## 解析与持久化

- 修复旧 PDF 只读取前5页、缓存只保存前30000字符的问题。TXT/Markdown/JSON/日志、PDF、Word、CSV和Excel保存带位置的正文块；正文预览与完整索引分离。
- PDF 保留页码；Word 按正文与表格原始顺序保留段落/表格位置；CSV、Excel保留行号和工作表名。前60行、前20张表的旧结构预览继续供课表工具使用，后续行和工作表进入正文索引。
- 每块最多2000字符，同一位置内相邻块重叠120字符，避免关键词跨边界漏检。排序优先保留命中后的上下文。字符总量不重复计算重叠部分。
- `material_indexes` 保存解析版本摘要，`material_chunks` 保存按文件及片段编号定位的原文。并发重建处于同一数据库事务，不产生重复片段；物理清理资料时级联清理索引。
- 旧本地截断缓存按需从原文件重建，并补齐旧资料指纹。旧网页缓存或原文件缺失的旧缓存明确提示可能只有摘要。
- 损坏文档保留附件编号与失败状态，读取返回可解释错误；检索某一文件失败不会隐藏其他文件的成功结果。

API：`GET /api/materials/{file_id}`，参数 `part/count/revision`；`GET /api/materials/search`，参数 `query/file_id/project_id/file_offset/limit`。OpenAPI及前端类型同步。

Agent工具：`read_material`、`search_materials`。每次最多读取5段、检查20份文件；更多文件返回确定的后续调用及覆盖范围。错误片段或版本返回 `material_conflict` 与读取入口。项目自动上下文限制引用数量与摘录长度，完整原文通过片段工具读取。

## 边界与下一步

本地解析每份材料最多200万正文字符、PDF最多500页、每张表最多50000行；超出范围明确标记未解析。PDF无可提取文本的页面提示可能需要视觉识别；本批没有新增OCR或把扫描页假称为已读。Excel读取保存的单元格值，不重新计算公式。

正文检索是字面关键词匹配，不是语义检索；每批候选最多2000个，达到上限会提示缩小范围。检索命中不等于读完全文。普通网页抓取仍有原有响应和正文容量限制，本批没有把旧网页摘要升级为完整网页存档。

多文件分阶段阅读摘要、学习反馈和课程自适应、后续阶段扩充、真实供应商/弱模型内容质量评测仍待继续。超大材料的反复索引校验和跨多轮阅读效率也需进一步打磨。
