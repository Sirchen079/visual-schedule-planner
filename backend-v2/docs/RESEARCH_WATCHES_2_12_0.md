# v2.12.0：按项目定期补充资料

学习与研究页面新增“持续补充资料”。用户保存公开主题检索词后，可以按每天或每周、本机时刻自动检索，设置每次1–6份，选择是否重新读取搜索结果中已有的网页。首次升级默认关闭，已有项目不会自行联网；支持立即检查、修改、暂停和执行历史翻页。

后台只向所选网页服务发送保存的公开检索词，不自动把项目目标、私人背景或附件正文放入搜索。沿用设置中的内置/Tavily/MCP服务及服务授权；网页仍是参考数据，获取成功不代表事实核验或完整阅读。不调用语言模型生成结论，不自动增加任务或改写学习日历。

## 结果与恢复

- 运行期间每分钟检查到期项目。未运行期间不执行；重开后逾期计划只补查一次，下一次按设定的每天/每周时刻安排，不补跑全部历史周期。
- 每次执行先持久登记并领取唯一执行权；同项目同时点击或与后台撞车时不会并行执行。逐份保存结果，保留部分完成和明确失败。
- 新资料与正文变化沿用v2.11不可变网页快照，旧任务引用继续指向原版本；同正文重复检索不新增快照。
- 暂停、修改配置或归档项目后停止后续请求。已发出的单个网页请求可完成并保留结果；恢复项目时，仍开启的检索设置会继续生效。
- 异常退出留下的执行权20分钟后回收，保留中断历史并补查一次。单次联网超时小于此租期；正常运行每个操作前刷新执行权。
- 有新增/更新资料或新的失败时保存通知，内容未变化和同样失败不反复通知。通知点击打开对应项目，记录里的资料链接可直接分段阅读。
- 页面每15秒刷新执行状态。模型工具按每页2次返回历史并提供继续调用，避免把整份长期执行记录挤入聊天上下文。

## 实现与权限

新增`research_watches`和`research_watch_runs`表，旧库通过已有幂等建表启动流程补齐。`/api/research/projects/{id}/watch`读写配置，`/watch/run`立即执行；配置使用版本条件更新，避免覆盖并发修改。执行后提交时验证归属，不覆盖新配置或已回收的执行。

对话工具为`get_research_watch`、`configure_research_watch`、`run_research_watch`。配置属于confirm级别，沿用已有自主程度/审批权限；内置指导要求仅在用户明确要求持续联网时开启。生成项目、一般资料检索、进度跟进不会顺带开启订阅。
