# v2.7.0：随身对话、本机时间与课程调整

2026-09-06。继续迭代知时 v2；全能私人秘书的整体目标仍在进行中。

## 本轮行为

- 应用、托盘、安装包与界面统一使用暖米色和赤陶色图标，图形结合时钟与对话。SVG 为可编辑源，PNG 保留透明圆角，Windows ICO 包含16至256像素的7种尺寸。
- 悬浮窗展开即为完整 AI 对话：支持附件、流式回答、工具过程、确认卡片、停止和会话历史。收起和隐藏保留同一个对话组件，输入草稿和待确认操作不会丢失。可拖动、置顶、打开主界面；对话中的应用内页面链接转交主窗口。
- 每条用户消息记录当时的本机日期、时间、星期、时区偏移；每次模型请求前重新读取系统时钟，包括同一轮内的后续工具步骤和审批恢复。界面顶部时钟按秒更新，切回窗口、页面恢复与跨日会更新日期，跨日刷新今日日程。
- 新的日期换算工具支持今天、明天、后天、昨天、前天、本周/下周/下下周的星期、月底、下月底、N天前后和明确ISO日期。不确定的表达返回错误；旧消息的“明天”以旧消息日期为基准，已确认的具体日期不会因跨午夜自动顺延。
- 模型设置可明确选择 OpenAI Chat Completions、OpenAI Responses 或 Anthropic。Responses 使用本地完整历史，设置 `store=false`，不会依赖服务端保存的 response id 继续会话。第三方平台自己的日志与数据保留政策不由此设置保证。
- 学习项目可在尚未开始的步骤之前补充内容，或按用户要求替换该步骤。新顺序持久保存，后续重排与阶段追加仍沿用这个顺序。
- 替换保留原任务编号、附件和其他任务属性，更新标题、产出标准及预计分钟；超过单次时长会拆为后续步骤。修改前笔记、资料出处和安排保存在方案历史。
- 已完成、进行中或已有学习记录的内容不覆盖；含已有子任务的步骤可前插补充，不自动替换。手工时间默认保留，只有明确勾选或授权指定任务时才允许移动。时间不足时明确列出未排入项。

## 接口与实现

新增 `research_curricula` / `research_plan_edits` 表，分别保存项目任务顺序与变更前快照。启动时创建新表；原有任务不需要重建。顺序保存和实际任务/日历变更处于同一事务。

| 接口或工具 | 用途 |
| --- | --- |
| `POST /api/research/projects/{id}/revisions` | `version, mode, target_link_id, rationale, steps, feedback_ids, movable_task_link_ids` 生成预览 |
| `GET /api/research/projects/{id}/plans?before=...` | 已落实方案历史，每页20条 |
| `GET /api/research/plans/{id}` | 读取方案及变更前记录 |
| `POST /api/research/plans/{id}/apply` | 沿用事务、版本校验与权限门落实 |
| `preview_research_revision` | Agent 课程插入或替换预览 |
| `list_research_plans` / `get_research_plan` | 历史分页与方案分段读取 |
| `get_current_time` / `resolve_local_date` | 读取本机时钟及确定性日期换算 |

`target_link_id` 来自项目的 `tasks[].id`，并非实际任务 `task_id`。项目读取增加 `revision_targets`，给出当前是否允许插入、替换和移动。Agent 错误结果附准确的项目重读调用；确认卡片展示原内容、新内容、手工时间授权与未排入数量。

落实前重新检查项目版本、日历、笔记、进度、子任务和专注记录。预览后原安排已开始，即使新的建议时间还在未来，也拒绝移动原安排。事务失败回滚内容、资料关联、课程顺序及日历；相同方案并发/重复落实只产生一份结果。

悬浮窗加载同一本机后端的 `/?widget=1#/`，复用前端对话组件与SSE接口。原生IPC限定本次窗口的主frame、精确回环源、根页面及widget参数；应用内跳转拒绝外部地址。窗口尺寸为展开440×680、收起352×78，按显示器可用区域约束。历史的快速记事悬浮页面源文件保留，但本版不再将它们打入桌面壳。

协议实现参考 [OpenAI Function calling](https://developers.openai.com/api/docs/guides/function-calling)。实际智谱地址及所选模型的可用性通过用户授权的接口实测确认，不仅根据公开文档推断。

## 边界

“本机状态”本轮指系统时间、日期、星期和时区，以及现有任务摘要；未增加屏幕监视或其他设备信息采集。时间以本机系统时钟为准，不代替系统时间同步。工具不支持任意模糊中文日期，常规任务/日程仍允许用户有意录入历史记录。

课程调整针对一个目标步骤，允许前插多项或将一项替换为多个步骤；不提供批量任意删除或一键撤销。用户已完成的学习成果由真实记录和反馈确认，不能从“待办”状态证明用户绝对未开始，也不能由完成率推断掌握程度。

后台学习跟进仍为规则驱动，不会在没有对话时持续调用模型重新设计课程。程序退出后不继续运行。多材料综合、研究质量评估、预算账单及其他个人事务的长期主动处理继续推进。
