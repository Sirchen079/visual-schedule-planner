# v2.8.0 设置入口、模型列表与任务提醒

2026-09-06 构建，只迭代 v2。用户随后提出的模型能力、Token 容量、多模态路由和搜索服务配置属于下一增量，不在本版本完成范围内。

## 使用入口

- 左侧导航底部显示“设置”文字；设置页有分类导航。
- “悬浮窗与桌面通知”位于设置页最前面：显示/隐藏、置顶、收起、重置位置和桌面通知。隐藏状态会保留到下次启动；关闭系统弹窗后，通知仍保留在铃铛内。
- 悬浮窗顶部设置按钮和托盘“悬浮窗与功能设置”可直接打开对应设置。
- 自动跟进与秘书自动安排的开关集中展示，并说明后台运行条件与影响。外观、工作时间、模型、技能、外部工具、授权均有分类入口。
- 模型配置填入 Base URL 和 Key 后可点“获取模型列表”，选择模型，也可手动填写。获取列表不创建配置或保存 Key；点“添加”才保存。

## 实现与边界

桌面设置由受主窗口主 frame 和本次回环 URL 限制的预加载桥接处理。`widget.json` 保留位置与悬浮状态，`desktop.json` 保存通知偏好。设置页、悬浮窗、托盘之间即时同步，文件保存失败会向设置页报告错误。

`POST /ai/configs/models` 使用表单填写的服务地址查询模型列表，支持 OpenAI Chat Completions、Responses 和 Anthropic。请求不跟随重定向，不显示上游原始错误正文；分页限制三页、最多 500 项、单页最多 1 MiB，超时与认证失败有可读提示。使用无环境代理的直接连接；尚未提供代理设置。不提供模型列表接口的服务仍可手动填写模型名称。模型属性和 Token 上限尚未作为可编辑配置接入。

任务提醒现在合并 `due_date` 与独立的 `due_time` 计算和展示截止时间；未填写独立时间时保留原 datetime 行为。新增持久扫描游标，首次无游标回看 35 分钟，之后休眠/重启最多补七天。旧积压提醒按任务折叠为最近一次，有近期提醒时使用近期提醒；完成、删除或关闭提醒的任务不补发。通知及游标同事务提交，数据库唯一约束去重。

PATCH 明确传 null 可清空截止日期/时间；AI 工具增加明确的 `clear_due_date` / `clear_due_time` 参数，空提醒数组可关闭提醒。新增提醒参数校验，损坏的旧提醒数据不会阻断其他任务。任务通知可跳转并定位任务，删除后显示空状态；“全部已读”不再只处理前 1000 条。

程序真正退出时不执行后台任务，下次启动才补发。独立 Event 日程提醒尚未实现。Windows 是否实际展示系统弹窗仍受系统通知设置控制。本机 Ctrl+Alt+Z 已被其他程序占用，界面会如实显示，可使用设置或托盘。
