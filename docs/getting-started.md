# 知时使用教程

## 从这里开始

左侧图标可以打开各个栏目，把鼠标停在图标上就能看到名称。窗口较窄时，对话区也从这里打开。

初次使用，可以跟着新手指引保存一条待办，再用“学习目录”选择感兴趣的栏目。点“收起提示，按步骤操作”可以暂时收起指引，完成后点右下角按钮继续。

教程目录支持搜索，输入“付款”“找回”“截止”等词就能找到相关章节。点章节上方的“打开实际页面，跟着箭头学”，可以直接进入该栏目的指引；阅读完整教程后也能返回原步骤。当前打开软件期间，还可以从教程底部“继续栏目学习”接着看。

任务、日记和收支可以直接手动记录。需要 AI 帮忙时，再打开“AI 接入”教程配置模型。

## 记下第一件事

1. 在最左边找到 **看板**，点击它。
2. 在页面上方找到 **新建任务**，点击它。
3. 点击写着“任务标题（必填）”的输入框，输入要做的事，例如“取快递”。
4. **截止日期和优先级可以先不改**。只填标题也能保存。
5. 点击 **创建**，等任务出现在看板中。

输入有误可以直接修改。点“创建”保存任务，点“收起”隐藏表单。

新手指引会用亮框和箭头指向这些按钮，保存任务后自动进入下一步。

## 做完以后，怎样勾选完成

1. 打开 **看板**，找到刚才的任务。
2. 点任务前面的圆形勾选按钮。
3. 任务会变为“已完成”；按状态分组时，可以在“已完成”一列找到。

误勾了，可以再点一次取消完成。普通待办放在看板即可，需要排期时再安排时间。

## 对话：用一句话交代事情

在对话区告诉 AI 要做什么，也可以上传附件。宽窗口左侧常驻对话区，窄窗口点左侧“对话”打开。

1. 在“设置 → AI 模型”添加并启用配置。
2. 在底部输入框写下要求；点回形针选择附件，点向上箭头发送。
3. 收到问题卡时填写答案并提交；收到审批卡时查看操作内容，选择同意或拒绝。
4. 到看板、日历或账本查看保存结果。新话题点顶部“＋”新建会话，历史会话从列表找回。

同一件事可以在当前会话继续补充。主窗口和悬浮窗各自保存会话与草稿。问题卡、审批卡的用法见后文。

## 梳理想法与头脑风暴

想法还不清楚时，可以直接说“帮我理清需求”或“陪我想想这件事”。默认模式每轮问 1～3 个关键问题，结合你的回答整理选择和下一步。还不知道的地方可以跳过，随时说“先总结到这里”。

想把全部决策讨论清楚，点输入框下方的“头脑风暴”，再说出你的想法。知时会按问题之间的依赖逐轮追问，每个问题附上建议和理由。已经回答过的内容会继续沿用；需要修改时直接说明。

所有决策讨论完后，知时会请你确认理解是否一致，再整理需求与决策摘要。头脑风暴会在同一会话中保持开启，再点一次按钮可以退出；新建会话默认关闭。退出后，可以继续让知时把讨论结果落实为任务或安排。

“计划”按钮用于先提交执行计划、批准后执行。头脑风暴和计划分别开启。

两种思路梳理流程都内置在知时中，可以在“设置 → 技能”查看。完整决策访谈改编自 Matt Pocock 的 grilling，采用 MIT 许可。

## 对话里的排版与公式

用户消息和 AI 回复都支持常见 Markdown：`# 标题`、`**粗体**`、`*斜体*`、`~~删除线~~`、列表、引用、链接、表格和代码块。代码放在三个反引号围成的代码块中，第一行可注明 `python`、`javascript` 等语言；代码里的符号会按原文显示。

数学公式支持以下写法：

| 类型 | 写法示例 |
| --- | --- |
| 行内公式 | `$E=mc^2$` 或 `\(E=mc^2\)` |
| 独立公式 | 在单独一行写 `$$`，下一行写公式，再用一行 `$$` 结束；也可用 `\[` 和 `\]` 包围公式 |
| 数学代码块 | 在代码块第一行注明 `math`，其中的内容会显示为独立公式 |

例如发送“解释公式 `$\frac{a}{b}$`”，分数就会排版显示。矩阵可用 `\begin{pmatrix}...\end{pmatrix}`，多行推导可用 `\begin{aligned}...\end{aligned}`，放在独立公式中。

公式使用 **LaTeX 数学语法**。有错误或不支持的命令会保留为可读文本。想原样展示写法时，用反引号包起来；普通美元符号也可写为 `\$`。

公式字体已内置，无需再接入网络服务。历史消息与实时回复使用相同排版；较长的公式、表格和代码块可在消息内横向滚动。

## 学习与研究：把目标变成分步计划

把学习资料、步骤、时间安排和进度放在一个项目里。

1. 点“新建项目”，填写主题、预期成果、开始日期和每天可用时间，保存项目。
2. 在“项目资料”上传材料、添加链接或从资料库选择。配置联网服务后还可检索资料。
3. 点“手动拟定步骤”，或让 AI 根据资料制定计划。点“预览时间安排”，检查后点“确认落实计划”。
4. 在“实际进度”记录完成情况和遇到的问题，按进度调整内容或重新预览排期。

计划落实后，可在看板和日历查看任务与排期。预览中有步骤未排入时，检查日期范围、可用星期、每天时段和单次最长时间。

## 今日：先看今天怎么过

查看今天的安排、下一项事情、时间冲突和空闲时段。

1. 看“现在时刻”和下一项安排，确认开始时间与地点。
2. 查看冲突提示和“今日空闲”，空闲时段按已录入的安排计算。
3. 右侧按时间列出今天的安排。其他日期去日历查看，未排时间的待办去看板找。
4. 准备专心做一件事时，打开右下角的专注计时，记录投入时间。

当天没有安排时，列表会留空。临时外出等尚未录入的事情，也要记得留出时间。

## 收件箱：先核对，再落实

把通知、收据或想法整理成待办、日程和收支草稿，在这里核对并保存。

1. 在对话中上传材料，请 AI 整理到收件箱；也可以点“手动整理”。
2. 选择“待办 / 日程 / 收支”，填写内容和原文依据，点“保存候选”。
3. 在“待确认”中点“核对 / 编辑”，补齐待澄清的信息，再点“确认落实”写入看板、日历或账本。
4. 在“已落实”中点链接查看记录。不需要的候选可点“忽略”，以后还能修正并重新整理。

核对时可对照通知中的日期、地点或收据金额。信息不清楚就留在“待确认”，查清后继续处理。已落实的内容通过链接查看和管理。

## 日历：查看和修改具体时间安排

按日、周、月查看时间安排，编辑日程或导出日历文件。

1. 点“日 / 周 / 月”切换视图，左右箭头翻页，“今天 / 本周 / 本月”回到当前日期。
2. 点已有日程块查看并编辑，保存修改。重复日程的修改会作用于整个系列。
3. 新增日程可直接告诉 AI，或在收件箱手动整理为“日程”后确认落实。
4. 点右上角“导出日历”保存 ICS 文件，再导入手机日历。时间改动后需要重新导出。

日历同时显示独立日程和任务排期。独立日程在详情中编辑，任务内容到看板修改。导入手机的是导出时的副本，重新导入时请处理手机上的旧记录，手机提醒也要在手机端设置。

## 看板：管理要做的事情

记录待办、查看截止日期和优先级，把大任务拆成子任务。

1. 点“新建任务”，填标题，按需设置截止日期和优先级，点“创建”。保存后会出现任务卡片。
2. 点“按状态 / 按日期”切换分组，查看进行中、已完成或逾期等任务。
3. 做完后点任务前面的圆圈，误点可再点一次取消。子任务可以分别勾选。
4. 需要排期时，告诉 AI 任务名称和可用时间。删除的任务可到左侧回收站恢复。

截止日期是最晚完成时间，预计分钟是估算所需时长；要在日历中查看任务，还需要安排具体时段。找不到新建任务时，检查当前分组。

## 时间轴：提前看任务截止和负载

按日期查看未来 14 天的任务截止时间和排期，找出任务集中的日子。

1. 从上到下查看日期：“截止”标记表示任务到期，具体时段表示已排期。
2. 右侧的预计分钟数来自任务时长估算，可用来判断当天任务量。
3. 列表为空时，到看板设置任务截止日期，或让 AI 安排任务时间。
4. 任务太集中时，告诉 AI 要调整的任务和日期。会议等独立日程到日历查看。

预计分钟为空或为零时，可补填任务时长。更早的逾期任务到看板的逾期分组查看，两周后的安排到日历查看。

## 习惯：记录反复做的事

为散步、运动等每天或每周重复的事情打卡，查看次数和连续记录。

1. 点“新建习惯”，填写名称，选择每日或每周，设置目标次数后点“创建”。
2. 完成一次后，在习惯卡片上点“打卡”。
3. 误点可点击“今日已打卡”撤销。把鼠标停在近 14 天的小方块上，可查看当天次数。
4. 需要固定时间提醒时，另设日程或提醒。

关联了习惯打卡的关键结果会随打卡更新进度，手动填写的关键结果需要到目标页更新。

## 日记：留下当天的记录

按日期写日记、选择心情，随时回看过去的记录。

1. 在顶部选择要写的日期。
2. 在内容框写日记，按需选择心情。
3. 点“保存这一页”，“未保存”提示消失后就保存好了。切换日期或栏目之前记得保存。
4. 点击历史列表中的日期，回看或继续编辑那一天的日记。

保存失败时，先保留文字，再按报错重试。删除日记后无法从回收站恢复。日记中提到的日程和提醒，可到对话区另行安排。

## 账本：记收支，也管待付账单

记录收支、查看月度汇总，设置待付款的周期账单和到期提醒。

1. 点“记一笔”，选收入或支出，填写日期、金额、币种、分类和账户，点“保存账目”。
2. 按月份、币种、账户或关键词筛选，查看明细和分类汇总。不同币种分别计算。
3. 固定开支点“添加账单”。付款后点“确认已支付”记账，已有账目可直接关联。
4. 误删账目时，勾选账本页面内的“回收站”，找到记录后恢复。

新建账单保存在待付列表，确认支付后才记为支出。查找账目时，留意月份、账户和币种筛选条件。

## 目标：用数字衡量长期成果

为长期目标设置可量化的关键结果，记录完成进度。

1. 点“新建目标”，填标题，按需填开始日期和备注，点“创建”。
2. 点目标卡上的“＋ 关键结果”，填写名称、目标值和单位，点“添加”。
3. 有进展时修改当前进度，离开输入框后会保存，进度条随之更新。
4. 阶段结束后可归档目标。需要学习步骤、资料和排期时，可新建学习与研究项目。

例如“整理家庭照片”可设置“完成 5 个相册”和“清理重复照片数量”两个关键结果。手动进度由你填写，关联习惯等自动统计类型则按相应记录更新。

## 资料库：保存、查找和阅读材料

保存文件和网页资料，按名称或正文查找内容，阅读并补充备注。

1. 点“上传资料”选择文件，上传完成后会出现在列表中。对话附件也保存在这里。
2. 顶部搜索框可找文件名；查找某句话时使用正文检索，按提示建立或刷新索引。
3. 打开材料阅读分段正文。内容缺失时查看解析状态和错误提示。
4. 要提取任务或制定计划，把材料交给 AI 并说明要求。误删文件可到左侧回收站恢复。

正文检索需要完成解析和索引，搜索不到时可先查看处理状态。让 AI 阅读长材料时，可以指定问题、页码或全文范围，并查看回复引用的来源。材料也可添加到学习与研究项目中。

## 日报周报：回顾一段时间

查看晨报、日报和周报，回顾一段时间的安排与完成情况。

1. 点“全部 / 晨报 / 日报 / 周报”筛选，选择一份报告阅读。
2. 生成新报告前添加并启用 AI 配置，再点“生成日报”或“生成周报”。
3. 查看报告日期，对照这一时段保存的任务和记录。
4. 删除报告时会弹出确认提示，删除后无法恢复。

报告根据已有记录由 AI 汇总。想采纳其中的建议，可以在对话中说明要创建的任务或日程。

## 回收站：找回误删的任务和资料

找回误删的任务和资料，或彻底删除已不需要的内容。

1. 查看“任务”和“资料”列表，刚删除的条目可点“刷新”获取。
2. 找到要取回的记录，点“恢复”。
3. 返回看板或资料库查看原记录，列表未更新时重新进入或刷新。
4. 确定不再需要的内容可以“彻底删除”，此操作无法恢复。

账目在账本页面内的回收站恢复。日记和报告删除后无法恢复。

## 设置：按需要调整软件

调整外观、悬浮窗和通知，配置 AI 及其他服务。

1. “悬浮窗与通知”中设置桌面小窗、通知和更新；“外观与 AI 助手”中设置主题、权限和工作时间。
2. 在“AI 模型”添加并启用模型，在“联网与视觉”配置搜索、网页和图片服务。
3. “技能”管理 AI 使用的规则与知识，“外部工具”连接 MCP 服务，“授权”查看和撤回永久授权。
4. 在“自动跟进”设置持续检查和自动安排。模型配置的详细步骤见 AI 接入教程。

暂时用不到的选项可以保留默认值。撤回永久授权后，后续操作会重新检查权限。

## 把几个栏目连起来：三种常见用法

**收到一份会议通知：** 对话里上传并要求整理 → 收件箱核对日期、地点和重复规则 → 确认落实 → 日历打开实际日程 → 今日查看当天安排。要带的材料可另外建待办，通知原文件保留在资料库。

**准备一个长期学习计划：** 学习与研究新建项目并添加资料 → 制定步骤 → 预览可用时间 → 核对后落实 → 看板做任务、日历看具体排期、时间轴提前看任务负载 → 在项目里记录反馈并调整。目标用来回顾量化成果，日记可以记录当天感受。

**管理固定开支：** 账本点击“添加账单” → 到期按提醒处理 → 实际支付后确认已支付，核对是否关联已有账目 → 用月份、账户和币种筛选实际收支。

## 待办、日程和提醒有什么不同

| 你的事情 | 应该怎么理解 | 可以怎样告诉 AI |
| --- | --- | --- |
| 这周找时间读一本书 | 待办：要完成，但时间可以灵活安排 | “帮我建一个任务：读完这本书。” |
| 明天下午三点开会一小时 | 日程：已经确定开始和结束时间 | “明天 15:00 到 16:00 开会，帮我放进日历。” |
| 怕忘记取快递 | 提醒：在指定时间通知你 | “明天 18:00 提醒我取快递。” |

接入 AI 后，把示例里的事情和时间换成你的安排，就可以发送。

日历中的“日 / 周 / 月”负责切换范围，左右箭头负责前后翻页，“今天 / 本周 / 本月”负责回到当前时间。点一个已有日程块，可以查看它的详细信息。

**提醒要在知时运行、电脑开机且未休眠时才能及时出现。** 在“设置 → 悬浮窗与通知”里检查通知开关。

## 第一次让 AI 帮忙

先点教程顶部的 **AI 接入**，按步骤添加并启用一个模型配置。

1. 回到对话区，点击最下方“告诉知时要做什么…”的输入框。
2. 输入“你好”，再点输入框右侧的 **向上箭头** 发送。
3. 等知时显示文字回复。等待时不用重复点发送。
4. 再输入“列出我的待办任务”，确认它能读取刚才保存的任务。
5. 熟悉后再让它创建日程、整理资料或安排计划。

**一次说清：做什么、什么时候、有什么要求。** 例如“明天下午三点开会一小时，提前半小时提醒我”，比“帮我弄一下”更容易得到准确结果。

## AI 问我问题或让我确认，怎么办

- **问题卡片**：缺少时间、范围或你的偏好时出现。先点选项，也可以在文字框补充；填好后点 **提交并继续**，原任务会接着执行。暂时无法回答时可以跳过。
- **操作审批卡片**：请先读清将修改或删除什么。正确才同意；不正确就拒绝，再说明你想怎么改。
- **正在处理**：先等结果。想停下来，可以点对话输入区的停止按钮。
- **执行计划**：“有执行记录”表示关联了成功的工具调用；“AI 汇报”表示还没有关联回执。重要安排请再打开看板或日历核对。

处理重要日期、金额或删除操作后，可以到相应页面查看结果。

## 文件、悬浮窗和关闭程序

**文件**：对话输入区的回形针按钮用于选择附件。选中后先确认文件名，再写清你希望 AI 做什么，例如“请从这份会议安排里整理日程”。使用外部 AI 时，相关消息和附件会发送给你配置的服务，不要上传不想交给该服务的内容。

**悬浮窗**：桌面上的小窗口也能对话。它和主窗口分别保存聊天与草稿。点“打开完整知时”回主窗口；点“收起”缩小它。被隐藏后，可以用 **Ctrl + Alt + Z** 唤回。

**关闭主窗口**：点右上角叉号后，安装版通常留在系统托盘运行。托盘在 Windows 右下角，隐藏图标可在小箭头里找到。需要彻底退出时，右键知时托盘图标，再选退出。

**更新**：打开“设置 → 悬浮窗与通知”，点“检查更新”。发现新版后按提示下载和安装。安装会重启知时，请等待窗口保存完成。

## 不会操作时，从这里找答案

| 遇到的情况 | 先做什么 |
| --- | --- |
| 找不到一个功能 | 把鼠标停在左边的小图标上，等名字出现；确认后点击。 |
| 找不到对话框 | 窗口较窄时，点左边“对话”图标。 |
| 一直提示没配置模型 | 在教程的“AI 接入”中，从“一步步配置”开始；添加后还要点“启用”。 |
| 任务没有出现在日历里 | 到看板找到任务，再告诉 AI 任务名称和要安排的时段。 |
| 误删了任务 | 先看左侧“回收站”，找到后恢复。 |
| AI 没回复或显示错误 | 打开“AI 接入 → 常见问题”，按错误提示逐项检查。不要连续重复发送。 |
| 想重新学习 | 点“使用教程 → 新手指引”；随时可以跳过，之后再看。 |

需要反馈问题时，打开**设置 → 诊断日志 → 导出诊断日志**，将生成的 ZIP 文件附在反馈中，并说明发生时间、操作步骤、预期结果和实际结果。日志覆盖软件运行问题，包括桌面启动、接口失败、后台异常、前端异常和 AI 请求。

日志将自动脱敏后再导出；个人数据全程保存在本地，此功能不会自动上传。导出仅保留错误类型、代码位置、接口耗时和用量等诊断信息，不含密钥、聊天正文、附件内容或个人路径。日志有容量上限，较早的问题可能需要复现后再导出。截图前仍请遮住 API Key、个人文件和聊天内容。
