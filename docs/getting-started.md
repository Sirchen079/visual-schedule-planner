# 知时使用教程

## 从这里开始：所有栏目都能查，也能跟着学

最左边的小图标是功能入口。把鼠标停在图标上会显示名字，看清后用鼠标左键点一下。窗口较窄时，对话区也从这一列打开。下面说的“输入”前，先点一下输入框；长页面用鼠标滚轮向下看。

**不需要先配置 AI 才能使用知时。** 可以先手动保存任务、日记和收支，再按“AI 接入”教程配置模型。

本教程为每个栏目分别说明用途、何时使用、具体步骤和容易混淆的地方。目录支持搜索，例如输入“付款”“找回”“截止”查相关章节。每个栏目章节上方的“打开实际页面，跟着箭头学”会带你找到入口和第一步。

按步骤尝试操作时，可以点指引里的“收起提示，按步骤操作”，完成后点右下角的返回指引按钮。当前打开软件期间，教程底部若显示“继续栏目学习”，可回到刚才的栏目；要重学基础练习，从指引的学习目录选择即可。

**新手指引**先带你实际保存一条待办，再逐一介绍全部栏目。指引里的“学习目录”可跳转、补学；“完整操作教程”看完后可返回原步骤。“已读”只表示你点过“看过了”，不代表已经执行操作。仅阅读不会自动创建样例或调用模型，关闭指引也不会删除你自己保存的内容。

容易混淆时先记住：**任务是动作，日程是时段，习惯是重复行为，目标是成果，资料是来源，收件箱是待核对内容。** 下面每个栏目都有进一步解释。

## 记下第一件事

1. 在最左边找到 **看板**，点击它。
2. 在页面上方找到 **新建任务**，点击它。
3. 点击写着“任务标题（必填）”的输入框，输入你真正要做的事，例如“取快递”。
4. **截止日期和优先级可以先不改**。只填标题也能保存。
5. 点击 **创建**，等任务出现在看板中。看到这条任务，才表示已经保存。

输入错了、还没点“创建”时，直接在输入框里修改即可。“收起”只是把输入表单藏起来，不等于保存。

新手指引会用亮框和箭头指向看板上的实际按钮与输入框。按提示点“新建任务”、填标题、点“创建”，保存成功后会自动继续。仅阅读或跳过指引不会创建示例数据；退出指引也不会删除已经保存的任务。

## 做完以后，怎样勾选完成

1. 打开 **看板**，找到刚才的任务。
2. 点任务前面的圆形勾选按钮。
3. 任务会变为“已完成”；按状态分组时，可以在“已完成”一列找到。

误勾了，可以再点一次取消完成。不是所有任务都需要排具体时间；普通待办先放在看板即可。

## 对话：用一句话交代事情

**用来做什么：** 向 AI 提要求、发附件、回答补充问题，并查看执行结果。宽窗口左侧常驻；窄窗口点左侧“对话”打开。

**什么时候用：** 例如：把这份通知整理成待办，先让我核对。

**一步步操作：**

1. 先在“设置 → AI 模型”添加并启用配置；没有配置时可先学其他栏目。
2. 在底部输入框写清事情、时间和要求；附件用回形针选择，再点向上箭头发送。
3. 出现问题卡时回答并提交；出现审批卡时核对后决定。等待时不用重复发送。
4. 完成后到对应栏目核对。新话题可点对话区顶部“＋”新建会话，历史会话从列表找回。

**容易混淆：** 对话是交代事情的入口。看板、日历和账本显示实际保存的结果；AI 提出建议不等于已经保存。

**操作后怎么核对：** 先用“列出我的待办任务”验证读取，再尝试写入。一个会话可连续补充同一件事，换话题再新建会话。主窗口与悬浮窗分别保留会话和草稿，不要误以为切窗口会自动接续另一边的聊天。遇到补充问题或审批，按后文对应章节处理。

## 对话里的排版与公式

用户消息和 AI 回复都支持常见 Markdown：`# 标题`、`**粗体**`、`*斜体*`、`~~删除线~~`、列表、引用、链接、表格和代码块。代码放在三个反引号围成的代码块中，第一行可注明 `python`、`javascript` 等语言；代码里的符号会按原文显示。

数学公式支持以下写法：

| 类型 | 写法示例 |
| --- | --- |
| 行内公式 | `$E=mc^2$` 或 `\(E=mc^2\)` |
| 独立公式 | 在单独一行写 `$$`，下一行写公式，再用一行 `$$` 结束；也可用 `\[` 和 `\]` 包围公式 |
| 数学代码块 | 在代码块第一行注明 `math`，其中的内容会显示为独立公式 |

例如发送“解释公式 `$\frac{a}{b}$`”，分数就会排版显示。矩阵可用 `\begin{pmatrix}...\end{pmatrix}`，多行推导可用 `\begin{aligned}...\end{aligned}`，放在独立公式中。

这项功能显示的是 **LaTeX 数学语法**，不是完整 LaTeX 文档编译器。尚未输出完或有错误的公式会保留可读内容；不支持的命令可能按原文显示。想原样展示写法时，用反引号包起来；普通美元符号也可写为 `\$`。

公式字体已内置，无需再接入网络服务。历史消息与实时回复使用相同排版；较长的公式、表格和代码块可在消息内横向滚动。

## 学习与研究：把目标变成分步计划

**用来做什么：** 围绕一个学习或研究主题，把资料、执行步骤、时间安排和反馈放进同一个项目。

**什么时候用：** 例如：两周学习基础摄影，每天投入半小时，并保留参考材料。

**一步步操作：**

1. 点“新建项目”，填写主题、想达到的结果、开始日期和每天能投入的时间，再保存。
2. 打开项目，在“项目资料”上传材料、添加链接或从资料库选择；联网检索按服务配置使用。
3. 点“手动拟定步骤”，或让 AI 结合资料制定计划；先“预览时间安排”，核对后再“确认落实计划”。
4. 在“实际进度”记录完成情况；计划不合适时调整内容或预览重排。尚未落实的预览不会自动变成安排。

**容易混淆：** 这里负责“学什么、按什么顺序做”；目标页负责衡量成果，资料库负责保存材料。计划落实后，任务与时间还能在看板和日历查看。

**操作后怎么核对：** 可以安排的星期、每天可用时段和单次最长时间决定能排多少内容。预览中若有未排入步骤，先检查日期窗口和可用时间；不能把“已预览”当作“已落实”。有进展或困难时记录反馈，再依据实际情况调整后续内容。完成任务只是记录执行情况，不代表软件已经证明你掌握了知识。

## 今日：先看今天怎么过

**用来做什么：** 集中查看现在的时间、今天的安排、下一项事情、冲突提示和可用空档。

**什么时候用：** 每天开始时先看这里，确认下一项安排和今天是否有时间重叠。

**一步步操作：**

1. 先看“现在时刻”和下一项安排，确认开始时间与地点。
2. 向下看冲突提示和“今日空闲”；空闲依据已记录的安排计算，没录入的事情不会计入。
3. 右侧按时间显示今天的安排；如果空着，先在看板记录任务，或让 AI 把确定时间的事情加入日历。
4. 想连续做一件事，可用右下角专注计时；它记录投入时间，不代替日程或任务。

**容易混淆：** 今日是当天总览。要翻到其他日期或修改独立日程，去日历；要找全部待办，去看板。

**操作后怎么核对：** 这里空白通常是当天没有已保存的安排，不一定是数据丢失。到看板查看未排时间的任务，到日历翻看其他日期。冲突和空闲都以软件已知记录为基础；临时外出等未录入事项，需要自己留出时间。

## 收件箱：先核对，再落实

**用来做什么：** 暂存从通知、收据或想法整理出的待办、日程和收支候选，核对后再正式保存。

**什么时候用：** 例如：收到一份会议通知，先确认日期、地点，再加入日历。

**一步步操作：**

1. 把材料发给对话区，请 AI 整理到收件箱；不用 AI 时也可点“手动整理”。
2. 选“待办 / 日程 / 收支”，保留原文依据，填好内容后点“保存候选”。
3. 在“待确认”中点“核对 / 编辑”，解决“待澄清的问题”；没有疑问后再点“确认落实”。
4. 到“已落实”点链接核对实际记录；不需要的候选可“忽略”，之后仍能修正并重新整理。

**容易混淆：** 收件箱不是邮箱，也不是资料库。“保存候选”只留下待确认内容；“确认落实”才写入看板、日历或账本。

**操作后怎么核对：** 原文依据用来核对来源，例如通知中的日期和金额。日期不清、金额不确定或无法判断是否已经付款时，先保留待澄清问题，确认后再落实。已落实条目应先通过链接查看现有记录，避免再手工创建相同内容。

## 日历：查看和修改具体时间安排

**用来做什么：** 按日、周、月查看日程，检查时间重叠，修改已有独立日程，并导出日历文件。

**什么时候用：** 例如：明天 15:00–16:00 开会，改到 16:00 开始。

**一步步操作：**

1. 点顶部“日 / 周 / 月”切换范围；左右箭头翻页，“今天 / 本周 / 本月”回到当前日期。
2. 点已有日程块查看详情，按需编辑后保存；重复日程的编辑作用于整个系列，先核对范围。
3. 要新增安排，可让 AI 明确创建日程，或在收件箱手动整理为“日程”后确认落实。
4. 右上“导出日历”保存 ICS 文件，传到手机后导入；它不会自动同步后续修改。

**容易混淆：** 有标题的待办不一定排了时间。看板管任务；日历管具体安排；时间轴集中展示任务截止与排期。

**操作后怎么核对：** 日程与任务排期可能同时出现在日历。独立日程可以打开详情编辑；任务本身到看板管理。重复日程改动前尤其要核对整个系列。导出只是当时保存内容的文件副本，之后更改时间需要重新导出和处理手机上的旧记录。

## 看板：管理要做的事情

**用来做什么：** 把任务放进待办、进行中、已完成等分组，查看截止日期、优先级和子任务。

**什么时候用：** 例如：取快递、整理材料，或把一个大任务拆成几个小步骤。

**一步步操作：**

1. 点“新建任务”，填标题；截止日期和优先级按需设置，点“创建”后看见任务卡片才算保存。
2. 用“按状态 / 按日期”切换分组；按日期时能区分逾期、今天和之后到期的任务。
3. 真正做完后点卡片前的圆圈；子任务有自己的勾选按钮，误点可再次点击取消。
4. 删除的任务进入左侧回收站，可恢复。需要把任务安排到某天时，可明确告诉 AI 任务名称和可用时间。

**容易混淆：** 任务是要完成的事情，不必一开始就有具体时段。设截止日期也不等于安排了开始和结束时间。

**操作后怎么核对：** “截止日期”表示最晚哪天完成；“预计分钟”表示估算投入；安排到具体时段是另一件事。任务拆分后逐项勾选子任务。看不到刚创建的任务时，先检查当前分组和列表，不要马上重复点创建。

## 时间轴：提前看任务截止和负载

**用来做什么：** 把未来 14 天的任务截止日期和任务排期排成一列，提前发现哪几天集中或忙碌。

**什么时候用：** 例如：本周有三件事同一天截止，先调整顺序或分几天完成。

**一步步操作：**

1. 从上到下按日期查看，带“截止”的是那天到期的任务，带时段的是已安排的任务。
2. 看右侧预计分钟数判断任务负载；它是估算，不是已经实际花掉的时间。
3. 如果没有条目，先到看板给任务设置截止日期，或让 AI 把任务排到某天。
4. 发现太集中时，明确告诉 AI 要调整哪个任务和哪一天；要查看独立日程，回到日历。

**容易混淆：** 这里展示任务截止和任务排期，不是完整日历，也不显示所有独立会议等日程。

**操作后怎么核对：** 时间轴适合提前发现任务集中，不是创建入口。预计分钟为空或为零，可能是任务没有估算时长。已经到期很久的任务要回看板查看逾期分组，未来两周以外的安排也不会全部出现在当前时间轴。

## 习惯：记录反复做的事

**用来做什么：** 为每天或每周重复做的事情打卡，查看累计次数、连续天数和近 14 天记录。

**什么时候用：** 例如：每天散步一次、每周运动三次。

**一步步操作：**

1. 点“新建习惯”，输入名称，选择每日或每周，再填目标次数，点“创建”。
2. 实际做过之后，在相应卡片上点“打卡”；观察次数和状态是否更新。
3. 误点后，再点卡片上的“今日已打卡”可撤销；近 14 天的小方块可悬停查看当天次数。
4. 想按固定时间提醒或占用时段，需要另外安排日程或提醒，不能只靠创建习惯。

**容易混淆：** 取一次快递是任务；反复坚持散步是习惯。打卡记录完成次数，不会自动占用日历时间。

**操作后怎么核对：** 每日目标和每周目标的统计范围不同，创建时先选对周期。卡片上的次数与连续记录帮助回顾，但没有打卡不一定代表你没做，做过也需要记录。关联了习惯打卡类型关键结果时，相关目标进度可随打卡滚动；普通手动关键结果仍需要你更新。

## 日记：留下当天的记录

**用来做什么：** 按日期写文字、选择心情，之后从历史列表回看。

**什么时候用：** 例如：记录今天完成了什么、遇到什么问题、明天想改进什么。

**一步步操作：**

1. 先在顶部选择日期，确认右侧页头显示的是你要写的那一天。
2. 在内容框输入文字，心情可以按需选择。
3. 点“保存这一页”，确认“未保存”提示消失；切换日期或栏目之前先保存。
4. 历史列表中点日期回看或继续编辑；不要为了结束编辑而点“删除此页”。

**容易混淆：** 日记是你写下的记录；日报周报是汇总报告。写“明天开会”不会自动创建日程或提醒。

**操作后怎么核对：** 切换日期是在打开另一页，不是在给当前文字修改日期。看到“未保存”时先保存；保存失败时保留文字并根据错误重试，不要直接离开。删除日记不能从任务与资料回收站恢复。

## 账本：记收支，也管待付账单

**用来做什么：** 记录已发生的收入和支出，按月份、账户和币种汇总；周期账单管理以后要付的钱。

**什么时候用：** 例如：记一笔交通支出，并提醒下个月缴费。

**一步步操作：**

1. 点“记一笔”，选收入或支出，核对日期、金额、币种、分类和账户，再点“保存账目”。
2. 用月份、币种、账户或关键词筛选，核对明细和分类汇总；不同币种分别计算。
3. 固定开支从“添加账单”建立；真正支付后点“确认已支付”，已有账目可关联，避免重复记录。
4. 误删账目时勾选本页“回收站”找到后恢复；左侧的回收站不显示账目。

**容易混淆：** 收支记录是已经发生的钱；待办账单是需要支付的事情，创建账单不会立刻记成支出。账目的回收站在账本页面内。

**操作后怎么核对：** 金额、日期和币种录错会直接影响汇总。保存后用同一月份、账户和币种筛选核对；不同币种不自动换算相加。待付账单即使已到期，也不能据此假定已经付款，只有实际支付后才确认已支付。

## 目标：用数字衡量长期成果

**用来做什么：** 定义想达到的成果，并用“关键结果”记录可以量化的进度。

**什么时候用：** 例如：整理家庭照片，以“完成 5 个相册”作为关键结果。

**一步步操作：**

1. 点“新建目标”，填标题，按需填开始日期和备注，再点“创建”。
2. 在目标卡上点“＋ 关键结果”，输入成果名称、目标值和单位，再点“添加”。
3. 实际有进展后，修改关键结果的当前进度数字；离开输入框时会提交更新，核对进度条。
4. 阶段结束可“归档”；如果需要详细学习步骤、资料和排期，另建学习与研究项目。

**容易混淆：** 目标管成果，任务管动作，习惯管重复行为。完成某条待办不会自动等于关键结果已达成。

**操作后怎么核对：** 一个目标可以有多个关键结果，例如“整理照片”下面放“完成相册数量”和“清理重复照片数量”，单位分别填写。这里的手动进度需要依据实际成果填写；如果通过 AI 建立了关联习惯等自动统计的关键结果，要按其类型理解进度来源。

## 资料库：保存、查找和阅读材料

**用来做什么：** 集中保存附件、上传文档和网页资料，按名称或正文搜索，阅读内容并补充备注。

**什么时候用：** 例如：把说明书、会议材料放进来，之后查找其中某段内容。

**一步步操作：**

1. 点“上传资料”选择文件，等待它出现在列表；对话中的附件也能在这里找到。
2. 用顶部搜索框按文件名筛选；要搜正文，使用页面里的正文检索，并按提示建立或刷新索引。
3. 打开材料查看分段正文；解析状态、范围限制和错误提示决定当前能读到多少内容。
4. 需要生成任务或计划时，再把材料交给 AI 并说清用途；误删资料到左侧回收站恢复。

**容易混淆：** 资料库保存材料；收件箱保存待核对的候选；学习与研究把材料用到一个具体项目。上传文件不等于已经创建日程。

**操作后怎么核对：** 按名称搜索和正文检索用途不同：记得文件名用前者，想找某句话用后者。正文无法解析或尚未索引时，搜索不到不等于文件里没有。需要 AI 阅读时说明想回答哪个问题、要处理哪些页或是否需要覆盖全文，并核对返回的来源范围。

## 日报周报：回顾一段时间

**用来做什么：** 查看晨报以及 AI 汇总生成的日报、周报，回顾安排和记录。

**什么时候用：** 例如：周末回顾这一周做了什么、哪些事情还没完成。

**一步步操作：**

1. 用“全部 / 晨报 / 日报 / 周报”筛选已有报表，点列表中的一份查看正文。
2. 需要新报告时，先配置并启用 AI，再点顶部“生成日报”或“生成周报”，等待完成。
3. 核对报告涵盖的日期与实际记录；记录不足时，报告也可能不完整。
4. 生成按钮会调用模型，指引不会替你点击；删除报告前看清确认提示，删除后不能从左侧回收站恢复。

**容易混淆：** 日记由你写，报表从已有记录汇总。报告中的建议不会自动成为新的任务或日程。

**操作后怎么核对：** 晨报、日报和周报覆盖的范围不同，先查看日期。报告会受原始记录和模型输出影响；例如没有打卡或没有保存的任务，不能指望报告补全真实经历。看到有用建议后，可明确告诉 AI 要落实哪一条，再回业务页面核对。

## 回收站：找回误删的任务和资料

**用来做什么：** 查看被移除的任务和资料，按需恢复；确认不再需要时才彻底删除。

**什么时候用：** 例如：误删一条待办，找到它后点“恢复”。

**一步步操作：**

1. 进入后分别查看“任务”和“资料”两块区域；刚删除还没看到时点“刷新”。
2. 核对名称和日期，对需要找回的条目点“恢复”。
3. 返回看板或资料库核对；如果原页面未更新，重新进入或刷新。
4. “彻底删除”不可恢复。学习本栏目只需阅读，不需要为了练习删除任何内容。

**容易混淆：** 左侧回收站只列出任务和资料；账目在账本页内恢复，其他栏目不能据此假定可恢复。

**操作后怎么核对：** 恢复会把原记录放回相应栏目，不会新建一个替代品。“彻底删除”与“恢复”作用相反，操作前看清文字。账目要到“账本”内部勾选回收站查找；日记、报告等栏目不适用这里的恢复步骤。

## 设置：按需要调整软件

**用来做什么：** 设置外观、悬浮窗、提醒、模型和扩展能力。每个分类负责不同部分，不需要一次全部配置。

**什么时候用：** 想显示悬浮窗找“悬浮窗与通知”；想接入模型找“AI 模型”。

**一步步操作：**

1. “悬浮窗与通知”管桌面小窗、通知与更新；“外观与 AI 助手”管主题、助手权限和可用工作时间。
2. “AI 模型”添加并启用对话服务；“联网与视觉”配置搜索、网页和图片相关服务。
3. “技能”提供给 AI 的规则与知识；“外部工具”连接 MCP 服务；“授权”查看和撤回永久授权。
4. “自动跟进”控制持续检查与自动安排。先阅读每项说明，暂时用不到的保持默认；API 细节可打开完整接入教程。

**容易混淆：** AI 模型、联网与视觉、技能、外部工具是不同能力；接通模型不代表其他服务也已配置。

**操作后怎么核对：** 建议按顺序设置：先选外观与通知，再按 AI 接入教程连接模型，最后只添加目前需要的扩展。授权影响哪些操作可以持续执行，撤回后后续操作会重新按权限规则处理。不要把联网服务密钥填进 AI 模型配置，也不要把模型上下文窗口当作每次回答长度。

## 把几个栏目连起来：三种常见用法

**收到一份会议通知：** 对话里上传并要求整理 → 收件箱核对日期、地点和重复规则 → 确认落实 → 日历打开实际日程 → 今日查看当天安排。要带的材料可另外建待办，通知原文件保留在资料库。

**准备一个长期学习计划：** 学习与研究新建项目并添加资料 → 制定步骤 → 预览可用时间 → 核对后落实 → 看板做任务、日历看具体排期、时间轴提前看任务负载 → 在项目里记录反馈并调整。目标用来回顾量化成果，日记可以记录当天感受。

**管理固定开支：** 账本点击“添加账单” → 到期按提醒处理 → 实际支付后确认已支付，核对是否关联已有账目 → 用月份、账户和币种筛选实际收支。账单提醒与收支记录分开；看到提醒不等于已经付款。

## 待办、日程和提醒有什么不同

| 你的事情 | 应该怎么理解 | 可以怎样告诉 AI |
| --- | --- | --- |
| 这周找时间读一本书 | 待办：要完成，但时间可以灵活安排 | “帮我建一个任务：读完这本书。” |
| 明天下午三点开会一小时 | 日程：已经确定开始和结束时间 | “明天 15:00 到 16:00 开会，帮我放进日历。” |
| 怕忘记取快递 | 提醒：在指定时间通知你 | “明天 18:00 提醒我取快递。” |

接好 AI 后才能用这些对话示例。请把例子里的事情和时间换成你自己的，不要原样发送不需要的安排。

日历中的“日 / 周 / 月”负责切换范围，左右箭头负责前后翻页，“今天 / 本周 / 本月”负责回到当前时间。点一个已有日程块，可以查看它的详细信息。

**提醒要在知时运行、电脑开机且未休眠时才能及时出现。** 在“设置 → 悬浮窗与通知”里检查通知开关。退出知时或电脑关机后，不会像手机闹钟一样继续提醒。

## 第一次让 AI 帮忙

先点教程顶部的 **AI 接入**，按步骤添加并启用一个模型配置。没有配置时，不必在对话框里反复发送。

1. 回到对话区，点击最下方“告诉知时要做什么…”的输入框。
2. 输入“你好”，再点输入框右侧的 **向上箭头** 发送。
3. 等知时显示文字回复。等待时不用重复点发送。
4. 再输入“列出我的待办任务”，确认它能读取刚才保存的任务。
5. 熟悉后再让它创建日程、整理资料或安排计划。

**一次说清：做什么、什么时候、有什么要求。** 例如“明天下午三点开会一小时，提前半小时提醒我”，比“帮我弄一下”更容易得到准确结果。

## AI 问我问题或让我确认，怎么办

- **问题卡片**：缺少时间、范围或你的偏好时出现。先点选项，也可以在文字框补充；填好后点 **提交并继续**，原任务会接着执行。不会回答时可以明确跳过，不要随便编一个答案。
- **操作审批卡片**：请先读清将修改或删除什么。正确才同意；不正确就拒绝，再说明你想怎么改。
- **正在处理**：先等结果。想停下来，可以点对话输入区的停止按钮。
- **执行计划**：“有执行记录”表示关联了成功的工具调用；“AI 汇报”表示还没有关联回执。重要安排请再打开看板或日历核对。

AI 回复“建议这样安排”和“已经保存”，含义不同。涉及重要日期、金额或删除时，以页面中实际保存的记录为准。

## 文件、悬浮窗和关闭程序

**文件**：对话输入区的回形针按钮用于选择附件。选中后先确认文件名，再写清你希望 AI 做什么，例如“请从这份会议安排里整理日程”。使用外部 AI 时，相关消息和附件会发送给你配置的服务，不要上传不想交给该服务的内容。

**悬浮窗**：桌面上的小窗口也能对话。它和主窗口分别保存聊天与草稿。点“打开完整知时”回主窗口；点“收起”缩小它。被隐藏后，可以用 **Ctrl + Alt + Z** 唤回。

**关闭主窗口**：点右上角叉号后，安装版通常留在系统托盘运行。托盘在 Windows 右下角，隐藏图标可在小箭头里找到。需要彻底退出时，右键知时托盘图标，再选退出。

**更新**：打开“设置 → 悬浮窗与通知”，点“检查更新”。发现新版后按提示下载和安装。安装会重启知时，请等待窗口保存完成。

## 不会操作时，从这里找答案

| 遇到的情况 | 先做什么 |
| --- | --- |
| 找不到一个功能 | 把鼠标停在左边的小图标上，等名字出现；确认后点击。 |
| 找不到对话框 | 窗口较窄时，点左边“对话”图标。 |
| 一直提示没配置模型 | 在教程的“AI 接入”中，从“一步步配置”开始；添加后还要点“启用”。 |
| 任务没有出现在日历里 | 只有待办标题，不等于已经安排了时间。先到看板找它；需要安排时间时再明确告诉 AI。 |
| 误删了任务 | 先看左侧“回收站”，找到后恢复。不要继续点永久删除。 |
| AI 没回复或显示错误 | 打开“AI 接入 → 常见问题”，按错误提示逐项检查。不要连续重复发送。 |
| 想重新学习 | 点“使用教程 → 新手指引”；随时可以跳过，之后再看。 |

需要反馈问题时，打开**设置 → 诊断日志 → 导出诊断日志**，将生成的 ZIP 文件附在反馈中，并说明发生时间、操作步骤、预期结果和实际结果。日志覆盖软件运行问题，包括桌面启动、接口失败、后台异常、前端异常和 AI 请求。

日志将自动脱敏后再导出；个人数据全程保存在本地，此功能不会自动上传。导出仅保留错误类型、代码位置、接口耗时和用量等诊断信息，不含密钥、聊天正文、附件内容或个人路径。日志有容量上限，较早的问题可能需要复现后再导出。截图前仍请遮住 API Key、个人文件和聊天内容。
