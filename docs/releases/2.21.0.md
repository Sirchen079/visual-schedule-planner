# 知时 2.21.0

本次更新新增头脑风暴模式，并重新整理使用教程和新手引导的文案。

- **头脑风暴**：在对话输入框下方开启，逐轮讨论需求和决策。通过问题卡回答或补充信息，结束时整理摘要。模式在当前会话中保持，再次点击可以退出。
- **梳理想法**：默认对话中可以说“帮我理清需求”，每轮用少量关键问题帮助比较选择、确定下一步。
- **教程与新手引导**：精简重复解释和生硬句式，直接说明入口、步骤和保存结果。

原有 Plan 模式继续按“提交计划、审批后执行”的流程工作。

完整决策访谈参考 Matt Pocock 的 grilling，保留原文及 MIT 许可。

Windows 用户下载 `zhishi-Setup-2.21.0.exe` 安装，也可以在“设置 → 悬浮窗与通知”检查更新。
