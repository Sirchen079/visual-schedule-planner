# 知时 2.20.1

本版以 2.20.0 为基线，保留稳定的 AI 工具定义、请求末尾时钟、缓存设置、教程、数学公式渲染、自动更新和脱敏诊断功能。

新增缓存用量汇总接口 `GET /ai/cache/stats?days=7`，按输入 token 加权计算总体和各模型的缓存命中率，同时返回统计覆盖率。历史记录缺少缓存字段时不伪造命中率；无数据返回 null。每轮执行结果同时提供命中率和模型请求次数。

统计覆盖已有聊天用量记录（含子代理），未记入该表的后台报告和摘要不纳入平均值。缓存写入不算命中；服务商不返回缓存计数时保守计为零。缓存过期、首次请求及模型/工具变化仍可能降低命中，不能保证每次使用都超过 90%。

Windows x64 安装包名称为 `zhishi-Setup-2.20.1.exe`。安装包、blockmap 和 `latest.yml` 配套发布，现有应用可通过“检查更新”获取。2.x 数据目录及卸载保留数据的行为不变。
