# 知时 2.22.0

任务排期、开始日和截止日现在会同步显示在日历与今日，子任务随父任务展示。

- 从看板、日历、今日和时间轴打开完整任务详情，查看说明、子任务及全部排期；修改后各处同步刷新。
- 日历顶部的全天、截止及其他时段安排默认折叠，展开后按日期排列；日程编辑与提醒设置也可按需展开。
- 保留全天、时间未定和夜间安排，重叠日程并排显示。
- 修复时间轴选择 14 天却只加载 7 天排期的问题。
- 恢复交互式更新安装流程；安装程序启动失败时保留错误恢复机会，避免应用提前退出。

升级保留现有数据，无需重新安排已有任务。建议升级前备份数据。

若 Windows 明确提示智能应用控制阻止安装，请参阅 [README 常见问题](https://github.com/Sirchen079/visual-schedule-planner#更新安装包被智能应用控制拦截)。
