# 知时 2.23.0 · 时段问候与休息提醒

本版本基于正式版 v2.22.1（ef0906b20b95c045c1bc48331927fae40e17fe74）增量开发，保留自动更新、截图粘贴、附件体验等既有功能。

- 新增顶部时段问候，覆盖清晨、午间、下午、傍晚与深夜。
- 专注计时达到 90 分钟时提醒休息，可结束当前专注并开始休息计时。
- 文案内置，离线可用，不实时调用模型。
- 顶部提示适配深浅主题和窄屏，支持键盘操作。

休息提醒依据在知时中手动开启的专注计时，不监测其他软件中的工作时长。

下载 Windows x64 安装包，或从 2.22.1 应用内检查更新。SHA256SUMS.txt 提供文件校验值。

此前误传的 2.15.1 基于旧源码，不应作为本次功能更新使用；请使用本版本。
