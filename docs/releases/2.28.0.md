# 知时 2.28.0 · 对话文件夹附件与 Windows 词表修复

- 对话输入区新增文件夹按钮，可选择本地代码仓库或资料文件夹。AI 能按需列出文件、读取文件内容，并对文本文件进行关键词搜索。
- 文件夹随会话保存，移除附件后撤销该会话的读取权限。文件夹工具只读取本地文件；文档解析不会在原文件夹生成额外文件。
- 补齐文档读取的 2MB 大小限制；删除会话时同步清理附加的文件夹记录和搜索索引。
- 修复 Windows 从 Git 检出源码时，词表换行符变化导致校验失败、简单任务被误判为上下文超限的问题。已有 CRLF 词表也可正常加载，内容完整性校验继续生效。

Windows x64 用户可下载安装包，或在知时中检查更新。安装包、`.blockmap` 和 `latest.yml` 来自同一次构建；`SHA256SUMS.txt` 提供文件校验值。
