# 知时 2.24.0 · 视觉 MCP 由模型自主选择工具

本版本基于正式版 v2.23.0（99e46e3f6d5203f8f5c6afa034af4ce3a5526ed5）增量开发，保留自动更新、时段问候、休息提醒等既有功能。

- 视觉补充改为**服务器级授权**：开启后只需选择 MCP 服务器，不再要求预先指定工具、不再手写参数模板。
- 读取图片时由模型自行查询该服务器提供的工具，按其真实参数格式构造请求；系统只负责把图片数据注入 `{{image_data_url}}`（远程服务）或 `{{image_path}}`（受信任本地 stdio）占位符后执行。
- 取消视觉通道对「只读工具」与「只读免审」开关的强制要求，未声明只读的工具同样可被选用。
- 联网搜索与网页读取两条通道的只读约束保持不变。
- 保留必要边界：服务器身份指纹（改动连接配置后需重新保存设置）、stdio 服务器须显式信任、参数模板不得包含凭据。
- 计划模式与头脑风暴模式不提供读图入口，避免成为只读模式的副作用出口。
- 旧的视觉设置（含已选工具与参数模板）在本版本首次读取时自动剥离过期字段，无需重新配置即可继续使用。

视觉补充的授权范围是「你信任的这台 MCP 服务器及其工具集」；模型可在该服务器上调用任意工具，请只配置你了解并信任的服务。

下载 Windows x64 安装包，或从 2.23.0 应用内检查更新。SHA256SUMS.txt 提供文件校验值。
