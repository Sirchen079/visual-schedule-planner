# 知时

把待办、日程、账本和资料放在一起的桌面助手。可以手动记录，也可以接入自己的 AI 服务，用一句话安排事情、整理文件或制定计划。

**Windows x64 · 2.18.0 · MIT 开源**

[下载安装包](https://github.com/Sirchen079/visual-schedule-planner/releases/latest) · [使用教程](docs/getting-started.md) · [AI 接入教程](docs/ai-api-guide.md) · [开发指南](docs/development.md)

## 先用起来

1. 打开上面的下载页面，在 **Assets（附件）** 中下载名称以 `zhishi-Setup-` 开头、以 `.exe` 结尾的安装包，双击安装。**Source code 是源码压缩包，不能直接运行。** 安装版无需另装 Python 或 Node.js。
2. 打开“知时”。新安装且没有历史数据时，会自动显示新手指引，用弹窗、亮框和箭头带你点击实际按钮。点“暂时跳过”可退出，以后从 **使用教程 → 新手指引** 重看。
3. 先记一件事：**看板 → 新建任务 → 填标题 → 创建**。日期和优先级可以先不改；看到任务出现在看板里，就保存好了。做完后点它前面的圆圈。

不配置 AI，也能先手动管理待办、查看日程、记账。2.x 使用独立数据目录，不兼容或自动迁移 1.x 数据；使用旧版时请保留原应用和备份。

## 能做什么

| 功能 | 用途 |
| --- | --- |
| 待办与计划 | 任务、子任务、看板、时间轴、目标、习惯和专注计时 |
| 日历与提醒 | 日 / 周 / 月视图、重复日程、日程编辑、课程导入、冲突检查和 ICS 导出 |
| 账本 | 收支记录、分类汇总、周期账单和到期提醒 |
| 资料与研究 | 收集文件和网页、整理资料库、制定学习或研究计划、跟进进度 |
| AI 助手 | 对话、附件处理、工具调用、提问与操作确认；可选联网和 MCP 外部工具 |
| 桌面快捷操作 | 悬浮窗对话、托盘、通知和应用更新 |

AI 能力取决于所接入的模型、服务权限和配置。重要日期、金额和执行结果，请在相应页面核对。

## 接入 AI（可选）

从同一个模型服务商准备 **API Key（密钥）、Base URL（基础地址）、模型名称和接口格式**，再打开 **设置 → AI 模型 → 添加配置**。

按页面填写，点击“获取模型列表”选择模型，也可以手动填写名称。点 **添加** 后，还要在列表中点 **启用**；看到“启用中”，再回对话区发送“你好”测试。模型服务可能收费，由服务商结算。

没有账号或不认识这些名词，直接跟着 [AI 接入教程](docs/ai-api-guide.md) 操作。教程也内置在应用的“使用教程”弹窗中，断网可以阅读。

配置成功后，可以试试：“列出我的待办任务”“明天 15:00 到 16:00 开会，帮我放进日历”。上传附件时，说明希望它提取、总结还是安排；出现问题卡或审批卡时，先看清内容再回答或确认。

## 常见问题

| 问题 | 答案 |
| --- | --- |
| 找不到对话框？ | 窗口较窄时，点左侧“对话”图标。 |
| AI 连接失败？ | 检查配置是否启用，再按 [接入教程的排错表](docs/ai-api-guide.md#常见问题) 核对错误。获取到模型列表并不保证模型能调用。 |
| 任务为什么不在日历里？ | 待办标题不等于已安排开始和结束时间。先到看板找任务，需要排期时再明确安排时间。 |
| 关闭窗口后还会提醒吗？ | 留在托盘运行时可以；彻底退出知时、电脑关机或休眠期间，不能及时提醒。 |
| 能在手机日历查看吗？ | 日历右上角导出 ICS，再导入手机日历。这是一次性导出，不会自动同步；提醒设置请在手机端确认。 |
| 怎样更新？ | “设置 → 悬浮窗与通知 → 检查更新”，按提示下载并安装；也可从下载页面获取新安装包。 |
| 怎样备份数据？ | 从托盘彻底退出知时后，复制 `%APPDATA%\ZhishiV2` 整个文件夹。自定义目录以实际配置为准；模型密钥另存于系统凭据库，换电脑后需要重新填写。 |

## 数据与隐私

日程、任务、会话和附件保存在本机。调用外部 AI、联网检索或 MCP 时，相关消息、文件内容或查询可能发送给配置的服务；本地保存不等于离线 AI。模型密钥通过系统凭据库保存，配置列表不会回显。

程序面向本机桌面使用，后端默认仅监听回环地址，没有面向公网的账号认证。具体边界见 [安全说明](SECURITY.md)。

## 开发与参与

后端使用 Python / FastAPI，前端使用 Vue / TypeScript，桌面壳使用 Electron。[开发指南](docs/development.md) 包含环境准备、构建启动、测试和接口类型生成步骤。

- `backend-v2/`：业务逻辑、AI 工具、接口和测试。
- `frontend-v2/app/`：页面、组件和前端状态。
- `electron-v2/`：窗口、托盘、系统交互与安装包。
- `docs/`：用户教程和开发说明。
